# AR-проект: «AR Мебель» (задание №1) и «AR Охота за монетами» (задание №2)

Один проект Unity 2022.3 LTS + AR Foundation 5.1 + ARCore. Из него собираются два отдельных APK:
- **AR-Mebel.apk** — аналог IKEA Place, 14 моделей мебели.
- **AR-Monety.apk** — AR-игра со сбором монет на закреплённой поверхности.

## Как получить APK (≈ 15 минут)
1. Установите Unity Hub и Unity **2022.3 LTS** с модулями **Android Build Support** (+ OpenJDK, Android SDK & NDK Tools).
2. Hub → Add → выберите папку `ARStudentProject`. Если Unity предложит обновить версию — согласитесь.
3. Дождитесь импорта пакетов (нужен интернет). Проект настроится сам (меню **AR Student**).
4. Меню **AR Student → 4. Собрать оба APK**. Готовые файлы: `Builds/AR-Mebel.apk` и `Builds/AR-Monety.apk`.
5. Скопируйте APK на телефон и установите (разрешите установку из неизвестных источников).

Телефон: Android 7.0+ с поддержкой ARCore (список: developers.google.com/ar/devices), установлены «Службы Google Play для AR».

Если в консоли ошибка про ARCore: Edit → Project Settings → XR Plug-in Management → вкладка Android → включить **ARCore**.

## Как пользоваться
**AR Мебель:** подвигайте телефоном над полом → появится голубая сетка → выберите предмет внизу → коснитесь пола.
Касание предмета — выбрать; тянуть пальцем — переместить; щипок — размер; поворот двумя пальцами — вращение;
кнопки справа: крупнее/мельче, поворот, удалить, очистить, «Фото» (сохраняет в галерею).

**Монеты:** «Играть» → наведите прицел на пол → «Закрепить поле» → касайтесь экрана, робот едет в эту точку.
Монета +1, кристалл +5, звезда +10 очков и +8 сек. Красные шипы отнимают жизнь. 3 уровня, пауза, рекорд, перезапуск.

## Технологии и реализованные функции (для отчёта)
- Unity 2022.3, C#; AR Foundation 5.1 + Google ARCore XR Plugin 5.1.
- Обнаружение горизонтальных плоскостей (ARPlaneManager), лучи (ARRaycastManager), якоря ARAnchor — сцена не «плывёт».
- 3D-модели строятся кодом из примитивов в реальных размерах (14 предметов мебели; в игре 7 типов объектов:
  робот, монета, кристалл, звезда-бонус, платформа, шипы-препятствия, угловые столбы).
- Управление жестами: касание, перетаскивание, щипок, поворот двумя пальцами; интерфейс uGUI, строится кодом.
- Звуки синтезируются кодом (сбор, бонус, удар, победа, поражение). Скриншот → галерея Android (MediaStore).
- Игра: 3 уровня, таймер, 3 жизни, рекорд (PlayerPrefs), экраны старта / паузы / результата.
